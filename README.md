# Logic App / Azure Functions

This repository contains Azure Functions projects used with Logic Apps.

## Projects

- **my-first-function** – Simple Hello World HTTP-triggered function  
- **doc-processing** – Function for processing documents (`ProcessDocument.js`)

## Getting Started

1. Clone the repo  
2. Open each function folder in VS Code with the Azure Functions extension  
3. Install dependencies: `npm install`  
4. Run locally with Azure Functions Core Tools

## Tech Stack
- Azure Functions (Node.js)
- Logic Apps integration
